# nvim-secrets rules file
#
# Add your own secret rules here. One rule per line. Blank lines and lines
# starting with `#` are ignored. Copy this file to
# `~/.config/nvim/secrets-patterns.txt` to have it loaded automatically, or
# point the plugin and the bat-secrets / rg-secrets commands at it with
# `patterns_file` / `--patterns-file` / BAT_SECRETS_PATTERNS_FILE /
# RG_SECRETS_PATTERNS_FILE.
#
# There are three kinds of rule:
#
#   glob <pattern>      mask anything matching a wildcard pattern.
#                       `*` matches a run of characters up to a separator
#                       (whitespace, quotes, = , : ; ( ) { } < > | /),
#                       `?` matches a single such character.
#   keyword <name>      mask the value after `<name> = ` or `<name>: `
#                       (case-insensitive; add `_`/`-` yourself if you want).
#   regex <vim-regex>   a raw Vim "very magic" regex, for anything the other
#                       two cannot express. Bracket the part to mask with
#                       \zs and \ze.
#
# A bare line with no keyword prefix is treated as a glob.

# --- Examples: uncomment or edit these ---------------------------------------

# A token with a distinctive prefix.
# glob acme_*

# A variable whose value is a path to a key file.
# keyword RSA_KEY_FILE
# keyword signing_key

# A raw regex, e.g. a provider token shape you know.
